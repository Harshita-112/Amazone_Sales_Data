# Amazon Sales Dashboard

## Project Overview

This project focuses on analyzing an Amazon-style sales dataset using **Microsoft Power BI**. The dataset contains 6,000 sales records covering products, categories, customers, regions, quantities, prices, and payment methods.

I created this project to practice **data cleaning, data transformation, data analysis, and interactive dashboard development in Power BI**.

## What I Worked On

* Imported and explored the raw sales dataset.
* Cleaned the data using Power Query.
* Removed duplicate records and handled missing or invalid values.
* Standardized text fields and data types.
* Created additional fields required for analysis.
* Built visuals to analyze sales performance from different perspectives.
* Designed a multi-page interactive Power BI dashboard.

## Dashboard Pages

### 1. Sales Overview

This page provides an overall view of sales performance through:

* Total Sales
* Total Orders
* Average Order Value
* Units Sold
* Monthly Sales Trend
* Sales by Payment Method
* Sales by Region

### 2. Product & Category Analysis

This page focuses on product performance and includes:

* Sales by Category
* Top 5 Products by Sales
* Units Sold by Category
* Category-level comparisons

### 3. Regional & Customer Analysis

This page analyzes:

* Orders by Region
* Regional Sales Share
* Orders by Payment Method
* Customer-level information
* Regional performance comparison

## Key Insights

The dashboard helped identify patterns such as:

* Furniture was the highest-revenue category in the dataset.
* Sales were relatively distributed across the different regions.
* Credit Card and Debit Card contributed strongly to sales.
* UPI also represented a significant share of transactions.

## Tools Used

* Power Query
* Data Cleaning
* Data Transformation
* Charts and Visualizations
* Interactive Filters and Slicers

## Key Learning

This project helped me understand how to take raw sales data, clean and transform it using Power Query, and convert it into an interactive dashboard that can be used to analyze business performance.
